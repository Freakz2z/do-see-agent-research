# P12 fault-conditioned authorization reset

P11-B remains closed. Its zero-opportunity result cannot be repaired by adding
seeds, models, or tasks to the frozen population. The exploratory opportunity
funnel instead motivates a new estimand: how an Agent authorizes an irreversible
decision **conditional on** a trusted, exogenous post-receipt fault that
decouples its local success proxy from the protected target.

The P12 harness intercepts the first naturally proposed action that makes both
the local proxy and protected target true in an isolated copy. The same action
and byte-identical immediate receipt are then replayed across six same-prefix
continuations. In the echo and erased continuations, the trusted harness
injects a deterministic partial failure after that receipt and before the
authorization evidence is delivered. The local proxy remains positive while
the protected target becomes false. The verified continuation remains healthy
and supplies an independently verified positive control.

The primary paired contrast is submit under echo-L2 minus submit under
erased-L2. Both arms have the same false protected target, faulted filesystem
state, natural action, transcript, immediate receipt, and causal-lineage
abstraction. Only the polarity/source of the subsequent evaluation evidence
differs. A post-decision probe is administered only after the echo-L2 decision
is irreversible, so correct causal recognition cannot repair the decision.

This design estimates a stress-conditioned authorization vulnerability. It
does not estimate how often such partial failures occur naturally, how common
the failure is in production, or the unconditional false-approval rate. P11-B
and P12 therefore answer different questions: natural exposure versus policy
behavior under controlled exposure.

Four deterministic failure mechanisms are frozen: release-replica manifest
omission, migration partial rollback, stale rollout edge replica, and backup
snapshot metadata omission. Each was reproduced twice without a provider call.
In every case the pre-fault state passed both oracles and the post-fault state
kept the local proxy positive while failing the protected target. A separate
runtime preflight proved that the common workspace is unchanged by trigger
evaluation, all six continuations share the action receipt, echo-L2 and
erased-L2 share the same faulted state, and the verified control remains truly
successful.

The first live stage is a four-prefix DeepSeek pilot, one task per family at
seed 101. It is permanently excluded from confirmatory estimates and can only
select a preregistered route. If the mechanics and six-arm census pass and the
pilot contains a coherent self-echo signal, the frozen 72-prefix three-model
confirmatory census may run. If there is no echo/erasure separation, the next
route is a separately frozen evidence-policy ablation; if the model does not
naturally reach successful-action triggers, the next route is a separately
frozen scripted-action stress test. Neither fallback changes P12 outcomes or
thresholds after inspection.
